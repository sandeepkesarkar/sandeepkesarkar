# Sandeep Kesarkar

I build data and agentic systems and write up what breaks. I have spent twenty-plus years in software and data engineering; these days most of my hands-on time goes to LangGraph, BigQuery and LLM evaluation, in the open.

## What I'm building

- [bq-query-agent](https://github.com/sandeepkesarkar/bq-query-agent): ask plain-English questions of BigQuery. The model can only choose one of six pre-written queries; code validates the values and caps the cost, and a person approves the SQL before anything runs. Evaluated on held-out questions, with the misses written up.
- [agent-dev-kit](https://github.com/sandeepkesarkar/agent-dev-kit): a spec-first pipeline for AI-assisted development. Gates on tests and coverage, and the model that writes the code never reviews it.
- [fieldkit](https://github.com/sandeepkesarkar/fieldkit): self-hosted, human-in-the-loop automation for small service businesses, with hard daily budget limits.
- [salestools-analyst](https://github.com/sandeepkesarkar/salestools-analyst): a fine-tuned, fully local AI analyst for sales data. QLoRA, GGUF, Ollama, and an eval harness.

## How I work

Specs before code. Evals before claims. A person approves anything with side effects. When something I try makes things worse, I publish that too (see `LESSONS.md` in bq-query-agent).
